# Triple Espresso

Projeto desenvolvido como parte da Sprint 4 (HTML e CSS Avançado).

O objetivo foi criar o layout de um site para o café fictício da Biblioteca Triple Peaks, seguindo o briefing, a estrutura semântica e a metodologia BEM.

---

## Tecnologias Usadas

- HTML
- CSS
- Google Fonts (Inter e Noto Serif)

---

## Estrutura

- `index.html` — página principal
- `blocks/` — styles organizados por bloco
- `pages/` — styles global
- `images/` — imagens usadas no projeto
